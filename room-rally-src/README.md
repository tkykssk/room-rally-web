# Room Rally（Godot 4.6 ソース）

トラックで部屋の物を壊してスコアを稼ぎ、tier が上がるたびにトラックが 1.5 倍に大きくなって、さらに大きな物を壊せるようになるゲームです。
Web ビルド（リポジトリ直下）の元ソースを復元し、ステージ制と CrazyGames 向けの仕様を追加しました。

## ステージ

| # | ステージ | 広さ | 制限時間 | 物の数 / 総得点 | 構成 |
|---|---|---|---|---|---|
| 1 | Playroom | 48×40 | 60 秒 | 70 / 2510 | おもちゃ台（高さ 2.5）とスロープ、ベッドの上の小物 |
| 2 | Kitchen | 60×48 | 100 秒 | 104 / 4580 | カウンター列（高さ 4.5）へのまな板スロープ、アイランド、ダイニング、仕切られたパントリー |
| 3 | House | 80×60 | 120 秒 | 108 / 5830 | リビング・寝室・書斎の 3 部屋、ロフト（高さ 6）へのスロープ |
| 4 | Office | 100×72 | 170 秒 | 145 / 9360 | デスク島、会議室・休憩室・倉庫、中二階（高さ 6）へのスロープ |

- **高い所**：台・カウンター・ロフトの上の物は、スロープで登るか、トラックが大きくなってから届くようになります。
  - tier の閾値は床にある物の得点だけから計算するので、高い所の物を取らなくても tier は上がります。
  - ★3（全部壊す）には高い所の物も必要です。
- **★の基準**：★1 = 総得点の 25%、★2 = 60%、★3 = **全部壊す**。数値は配置から自動で計算します。
- **ルームクリア**：全部壊すとその時点で終了し、残り 1 秒につき 20 点のボーナスが入ります。
- **解放条件**：前のステージで★1 を取ると次のステージが遊べます。各ステージのベストスコアと★は `user://save.cfg` に保存されます。
- 配置データは `scripts/stages.gd` にまとめてあります。
  - 部屋の広さ：`hx` / `hz`
  - 内壁とドア：`walls`
  - 台：`platforms`
  - スロープ：`ramps`
  - 家具：`layout`
  - 家具の上の物：`on_top`
  - 散布する小物：`clutter`
  - 床の敷物：`rugs`

### 取れない物に当たったとき
- 箱の当たり判定は摩擦 0 にしてあり、少し跳ね返ります。登ったり、引っかかって止まったりしません。
- 当たると速度が落ち、カメラが少し揺れます。
- テーブルは天板と脚だけに当たり判定があるので、小さいうちは下をくぐれます。
- 視界を遮る家具や内壁は半透明になります。
- ドアは上まで開いています。大きくなったトラックでも部屋を移動できます。

### 調整の根拠
家具を避けて経路を探し、最寄りの壊せる物へ向かうボットを、ヘッドレスで全ステージ走らせました。ボットはスロープを使いません。

| ステージ | 全部壊すまで | tier 6 到達 |
|---|---|---|
| Playroom | 約 30 秒 | 約 20 秒 |
| Kitchen | 56〜82 秒 | 約 45 秒 |
| House | 床の物は約 70 秒（ロフトの物はスロープが必要） | 約 60 秒 |
| Office | 114〜190 秒 | 約 62 秒 |

人間はボットより遅いので、ボットの結果に余裕を持たせて制限時間を決めています。

## CrazyGames 対応
- **SDK v3**：`scripts/crazygames.gd`（autoload `CG`）で対応しています。
  - プレイ開始、ポーズ解除で `gameplayStart`。ポーズ、終了で `gameplayStop`。
  - リトライ、次のステージ、ステージ選択に移るときに midgame 広告を出します。広告中は一時停止し、音を消します。
  - ベスト更新時に `happytime` を呼びます。
  - CrazyGames 側のミュート設定に従います。
  - SDK が無い環境（ローカル実行や Vercel 版）では何もしません。
- **Web 書き出し**：`export_presets.cfg` の「Web (CrazyGames)」プリセットを使います。
  - スレッドは無効です。CrazyGames は iframe 内で動くので、COOP/COEP ヘッダーが不要な設定にしています。
  - SDK スクリプトは `html/head_include` で読み込みます。
  - 書き出し先は `build/web/` です。
- **1 ラウンドの長さ**：1〜3 分。
- **操作**：キーボード、パッド、タッチボタンに対応しています。
- **ポーズ**：P キーまたは Esc、画面右上の II ボタン、タブを離れたときに自動。
- **UI**：画面サイズに合わせて縮尺します。

### リリース手順
1. Godot 4.6.3 の Web 用エクスポートテンプレートを入れる。
2. Project → Export → 「Web (CrazyGames)」で書き出す。
3. `build/web/` の中身を zip にして、CrazyGames Developer Portal にアップロードする。
