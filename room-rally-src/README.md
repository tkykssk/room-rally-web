# Room Rally（Godot 4.6 ソース）

トラックで部屋の物を壊してスコアを稼ぎ、tier が上がるたびにトラックが 1.5 倍に大きくなって、さらに大きな物を壊せるようになるゲームです。
Web ビルド（リポジトリ直下）の元ソースを復元し、ステージ制と CrazyGames 向けの仕様を追加しました。

## ジャーニー（メインモード）

塊魂のように、1 つのつながった世界で大きくなり続けるモードです。ロード画面なしで、子ども部屋 → 家 → 庭 → 町へ広がっていきます。

| 区域 | 出入口と開く条件 | 主な中身 |
|---|---|---|
| 子ども部屋（スタート） | 両側のドアをおもちゃの箱がふさいでいる（tier 2） | おもちゃ、お菓子、文房具 |
| 家 | パティオと玄関を引っ越しの箱がふさいでいる（tier 4） | キッチン、リビング、廊下 |
| 庭（自宅の敷地） | ブロック塀の門（tier 6） | デッキ、花壇、砂場、物置、木 |
| 町 | ― | 住宅、アパート、商店、駐車場、電柱、自販機、公園、神社 |

- **時間**：最初は 75 秒です。tier が上がるたびに時間が延び、最大で約 3 分 40 秒になります。
- **終わり方**：時間切れで終了し、そこまでのスコアと大きさ（20cm 〜 約 7.7m）が出ます。世界の物を全部壊すと、その時点で終わって残り時間がボーナスになります。
- **壁が崩れる**：トラックが壁より十分大きくなると壁が崩れて通れるようになります。子ども部屋の壁は tier 5、庭の塀は tier 7、家の壁は tier 8 です。
- **大きくなった後の閉じ込め対策**：家のドアは幅 22 にしてあり、家の中で到達できる最大の大きさ（tier 7）でも通れます。
- **重さ対策**：
  - 区域の物は、入れるようになる 1 つ前の tier で読み込みます。読み込みは数フレームに分けて行います。
  - トラックよりずっと小さく、離れた物は自動で消します（点数は入りません）。これで、世界が広くても物の数を一定以下に保ちます。
- **町の作り**：`tools/town.py` が固定シードで生成します（ステージデータは `python3 tools/gen_stages.py scripts/stages.gd` で作り直せます）。碁盤目にはせず、PLATEAU の実際の町並みを参考にしています。
  - **道**：曲がった道、T 字路、行き止まりがあり、幅の広い幹線道路が 1 本通っています。
  - **区画**：大きさの違う区画を道沿いに並べ、さらに奥の区画（旗竿地）でも埋めています。
  - **建物**：住宅は 4 種類（切妻、寄棟、陸屋根、3 階建て）で、ほかにアパート、商店、駐車場、空き地があります。
  - **その他**：区画と区画の間は舗装にし、芝生は庭・公園・空き地だけにしています。

### 調整の根拠（ジャーニー）
経路探索ボットを 3 回走らせました。

| 項目 | 結果 |
|---|---|
| tier 6（町に出られる大きさ） | 55〜64 秒 |
| tier 9（最大） | 100〜123 秒 |
| 終了 | 197〜220 秒（世界をほぼ全部壊した） |

人間はボットより遅いので、多くの人は時間切れまでに町の途中まで進む想定です。★は 6000 / 25000 / 60000 点です。

## チャレンジ（ステージ）

| # | ステージ | 広さ | 制限時間 | 物の数 / 総得点 | 構成 |
|---|---|---|---|---|---|
| 1 | Playroom | 48×40 | 60 秒 | 70 / 2510 | おもちゃ台（高さ 2.5）とスロープ、ベッドの上の小物 |
| 2 | Kitchen | 60×48 | 100 秒 | 95 / 4365 | カウンター列（高さ 4.5）へのまな板スロープ、アイランド、ダイニング、仕切られたパントリー |
| 3 | House | 80×60 | 120 秒 | 101 / 5750 | リビング・寝室・書斎の 3 部屋、ロフト（高さ 6）へのスロープ |
| 4 | Office | 100×72 | 170 秒 | 145 / 9020 | デスク島、会議室・休憩室・倉庫、中二階（高さ 6）へのスロープ |
| 5 | Backyard | 144×116 | 180 秒 | 228 / 13595 | **屋外**。家の中からスタートし、そのまま庭へ出られる |

### Backyard（屋内 → 屋外）
庭の真ん中に家があり、家の中から始まります。ロード画面なしで外へ出られます。家の壁は内壁と同じ扱いなので、トラックを隠すと半透明になります。

外へ出る道は 3 つです。

| 出口 | 通れる条件 |
|---|---|
| キッチンのペットドア | 高さ 1.9 の低い開口。小さいうち（tier 0〜1）だけ通れる |
| パティオのドア | 引っ越しの箱（tier 3）でふさがれている |
| 玄関 | もっと大きい箱（tier 4）でふさがれている |

庭にあるもの：
- ウッドデッキ（ピクニックテーブル、グリル、パラソル、ビニールプール）
- 花壇と家庭菜園
- 砂場
- 滑り台付きの遊具の台（高さ 4.5）
- 果樹のある横庭
- 前庭（郵便受け、消火栓、街灯、駐車中のトラック）
- 物置と犬小屋

木やパラソルは、幹や柱にだけ当たり判定があります。柵の外には木と近所の家が見えます（飾りなので当たり判定はありません）。

家の中の物だけで tier 3 まで上がれるよう、このステージだけ tier の閾値を低めにしています（`tier_fractions`）。

- **高い所**：台・カウンター・ロフトの上の物は、スロープで登るか、トラックが大きくなってから届くようになります。
  - tier の閾値は床にある物の得点だけから計算するので、高い所の物を取らなくても tier は上がります。
  - ★3（全部壊す）には高い所の物も必要です。
- **★の基準**：★1 = 総得点の 25%、★2 = 60%、★3 = **全部壊す**。数値は配置から自動で計算します。
- **ルームクリア**：全部壊すとその時点で終了し、残り 1 秒につき 20 点のボーナスが入ります。
- **解放条件**：ジャーニーと最初のチャレンジは最初から遊べます。それ以降は、前のチャレンジで★1 を取ると遊べます。各ステージのベストスコアと★は `user://save.cfg` に保存されます。
- 配置データは `scripts/stages.gd` にまとめてあります。
  - 部屋の広さ：`hx` / `hz`
  - 内壁とドア：`walls`
  - 台：`platforms`
  - スロープ：`ramps`
  - 家具：`layout`
  - 家具の上の物：`on_top`
  - 散布する小物：`clutter`
  - 床の敷物：`rugs`

### 取れない物に当たったとき
- 箱の当たり判定は摩擦 0 にしてあり、少し跳ね返ります。登ったり、引っかかって止まったりしません。
- 当たると速度が落ち、カメラが少し揺れます。
- テーブルは天板と脚だけに当たり判定があるので、小さいうちは下をくぐれます。
- 視界を遮る家具や内壁は半透明になります。
- ドアは上まで開いています。大きくなったトラックでも部屋を移動できます。

### 調整の根拠
家具を避けて経路を探し、最寄りの壊せる物へ向かうボットを、ヘッドレスで全ステージ走らせました。ボットはスロープを使いません。

| ステージ | 全部壊すまで | tier 6 到達 |
|---|---|---|
| Playroom | 約 30 秒 | 約 20 秒 |
| Kitchen | 56〜82 秒 | 約 45 秒 |
| House | 床の物は約 70 秒（ロフトの物はスロープが必要） | 約 60 秒 |
| Office | 114〜190 秒 | 約 62 秒 |
| Backyard | 約 140 秒 | 約 100 秒 |

人間はボットより遅いので、ボットの結果に余裕を持たせて制限時間を決めています。

## CrazyGames 対応
- **SDK v3**：`scripts/crazygames.gd`（autoload `CG`）で対応しています。
  - プレイ開始、ポーズ解除で `gameplayStart`。ポーズ、終了で `gameplayStop`。
  - リトライ、次のステージ、ステージ選択に移るときに midgame 広告を出します。広告中は一時停止し、音を消します。
  - ベスト更新時に `happytime` を呼びます。
  - CrazyGames 側のミュート設定に従います。
  - SDK が無い環境（ローカル実行や Vercel 版）では何もしません。
- **Web 書き出し**：`export_presets.cfg` の「Web (CrazyGames)」プリセットを使います。
  - スレッドは無効です。CrazyGames は iframe 内で動くので、COOP/COEP ヘッダーが不要な設定にしています。
  - SDK スクリプトは `html/head_include` で読み込みます。
  - 書き出し先は `build/web/` です。
- **1 ラウンドの長さ**：1〜3 分。
- **操作**：キーボード、パッド、タッチボタンに対応しています。
- **ポーズ**：P キーまたは Esc、画面右上の II ボタン、タブを離れたときに自動。
- **UI**：画面サイズに合わせて縮尺します。

### リリース手順
1. Godot 4.6.3 の Web 用エクスポートテンプレートを入れる。
2. Project → Export → 「Web (CrazyGames)」で書き出す。
3. `build/web/` の中身を zip にして、CrazyGames Developer Portal にアップロードする。
