# Roll Up Room（Godot 4.6）

部屋の小物から家具まで、転がる玉にくっつけて大きくしていく 3 分間のゲームです。
`room-rally` の塊魂風の部分を切り出し、ゲームとして全体を作り直しました。

> 公開名について：「Katamari／塊魂」はバンダイナムコの商標なので、ストア表示やタイトルには使わない前提で **Roll Up Room** という名前にしています（コード内のクラス名 `Katamari` はプレイヤーには見えません）。

## 遊び方

| 操作 | キーボード / パッド | タッチ |
| --- | --- | --- |
| 前進 / 後退 | W・S / ↑・↓ / 左スティック上下 | 画面のどこかを触ってドラッグ（上下） |
| 旋回（カメラも追従） | A・D / ← → / 左スティック左右 | ドラッグ（左右） |
| ポーズ | Esc / P / Start | 右上の II ボタン |

- 玉の直径の 6 割より小さい物はくっつき、玉が大きくなります。それより大きい物は障害物です。
- 勢いよく障害物にぶつかると、直前に集めた物がこぼれ落ちます（拾い直せます）。
- 3 分後の玉の大きさで評価します：★ 1 m／★★ 3 m／★★★ 6 m。ベスト記録は保存されます。

## レビュー結果と改善内容

### ルール・ゲームデザイン
| 問題（改善前） | 改善 |
| --- | --- |
| スコアが閾値を超えるたびに 1.5 倍へ段階的に巨大化し、大きさとスコアが連動していない | 拾った物の大きさに応じて**連続的に成長**（`growth`／`growth_exponent`）。スコアは玉の大きさそのもの |
| 拾えるかどうかが手入力の「tier」で決まり、見た目の大きさと一致しない | 実寸（最長辺と体積の平均）と玉の直径を比べて判定（`PICK_RATIO`） |
| 目標がなく、タイマーも仮値（999 秒） | 3 分間＋★3 段階の目標、ベスト記録、タイトル／ポーズ／リザルト画面 |
| リスクがない | 高速衝突で直近のアイテムを落とす「こぼれ」を追加 |
| 大型家具 1 個で一気に巨大化してしまう | 1 個あたりの成長を +4% までに制限（`max_step_growth`） |

### ステージ構成
| 問題 | 改善 |
| --- | --- |
| 80×80 の床に約 80 個の物がまばらに置かれ、最初の成長まで約 160 秒かかる | 約 390 個。開始地点のマットに硬貨・ビー玉などを集め、最初の数秒から拾える |
| 物がランダムに散らばり、場所ごとの性格がない | キッチン／ダイニング／リビング／寝室／書斎／玄関のゾーン別配置。卓上の小物は、テーブルを巻き込むと床に落ちる |
| 大きさの段差（60〜100 cm 帯が 7 個しかない） | スーツケース、太鼓、ビーチボール、ギター、扇風機、巨大テディ等を追加し、各サイズ帯を埋めた |
| 壁が 3 m しかなく空が見え、部屋に見えない | 壁紙、幅木、窓、ドア、額縁のある高さ 2.4 m の壁、木目の床。カメラが壁の外に出たら壁が沈む |

### 見た目
| 問題 | 改善 |
| --- | --- |
| グロー強め＋青い環境光で全体が白飛び | ACES トーンマップ、暖色の太陽光、環境光を抑えて彩度を上げた |
| Kenney 家具がパステル調で単調／食器は色テクスチャが欠けて真っ白 | 素材名ごとに再配色（布は物ごとにアクセント色）。食器は個別に色付け（`Palette`） |
| 玉がただの縞模様の球で、拾った物が埋もれて見えない | ピンクのトゲ付きの玉。拾った物は表面に残り、成長に合わせて外へ押し出される |
| 拾っても手応えがない | 吸着アニメーション、キラキラ、拾った物の名前表示、サイズ到達の演出、衝突時の画面揺れ |

### UI・サウンド
- Fredoka フォント（OFL）で統一。サイズメーター＋★ゲージ、タイマー（残り 10 秒で赤く点滅）、トースト表示。
- 効果音 9 種と BGM ループを `tools/gen_audio.py` で合成しました（外部素材なし）。改善前は効果音 1 種のみでした。
- フォーカスを失うと自動でポーズします（タブ切り替えや広告表示に対応）。

### バグ修正
- 机と椅子の隙間で玉が完全に止まる → 障害物の摩擦を下げ、押しても動かないときは跳ねて脱出する。
- 巨大化した玉が壁を抜けて落下する → 部屋の範囲に位置を固定する。

## バランス調整の方法
`can_be_absorbed_by` を満たす一番近い物へ向かうボット（素朴なプレイヤー相当）を、ヘッドレスで 3 分間走らせました。成長係数を変えながら比べています。既定値（`growth` 1.2）では、30 秒で約 30 cm、2 分で 1.4 m、終盤に家具を巻き込み始めて 6 m 前後でした。

## 主な調整パラメータ
- `GameManager.game_duration` / `star_goals_cm` / `milestones_cm`
- `Katamari.growth` / `growth_exponent` / `max_step_growth` / `base_speed` / `speed_exponent` / `knock_speed_ratio`
- `Katamari.PICK_RATIO`（直径の何割まで拾えるか）
- `prop_spawner.gd` の `LAYOUT`（家具）/ `ON_TOP`（卓上）/ `ZONES`（散布。`t:` は手続き生成のおもちゃ、`k:` は Kenney モデル、`@1.8` で拡大）

## Web 書き出し（CrazyGames 向け）
- `export_presets.cfg` に Web プリセット（**Thread Support OFF**）を用意しています。Godot 4.6.3 の Web テンプレートを入れて書き出してください。
- 未着手：CrazyGames SDK（ロード／プレイ開始・停止／広告）の組み込み。`GameManager.state_changed` と `Audio.set_muted` に接続できるようにしてあります。
- 配置物が約 390 個あります。小物は影を落とさず、遠くでは描画しない設定ですが、ローエンドのスマホでは実機で fps を確認してください。
